Proyecto: ProtoMindTech - Base de Datos
Versión actual: 1.0
Descripción:
Este proyecto busca desarrollar y mantener una base de datos escalable y profesional
para la gestión de una empresa tecnológica.

Estructura de carpetas:
- 01_Codigo → Scripts SQL
- 02_Diagramas → DER y diagramas de arquitectura
- 03_Mapeos → Gráficos de mapeos
- 04_Backups → Copias de seguridad
- 05_PruebasConsultas → Testing SQL
- 06_Versiones → CHANGELOG y control de versiones
